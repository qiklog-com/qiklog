# QikLog Console — Android

Kotlin `WebView` shell. Package id: `com.qiklog.console`.

```bash
# From this directory (Android SDK required)
./gradlew :app:installDebug

# Point at local dashboard from the emulator
./gradlew :app:installDebug -PQIKLOG_APP_URL=http://10.0.2.2:5081
```

Or open the `android/` folder in Android Studio and Run.

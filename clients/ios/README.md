# QikLog Console — iOS

SwiftUI + `WKWebView`. Bundle id: `com.qiklog.console`.

```bash
open QikLogConsole.xcodeproj
```

Set your Development Team under Signing, then Run on a simulator or device.

Override start URL in the scheme: Product → Scheme → Edit → Run → Arguments →
Environment Variables → `QIKLOG_APP_URL` = `http://localhost:5081`.
